# Lili 五阶段研究：调用规划、积分与不限额任务

本次修正针对“从 arrow bag quiver 大方向研究到 HTML 开品文档”的对话流程。以下规则更新旧文档中“必须填写1–30次上限”“阶段预测全部未知”的要求；不改变原始 Skill、账户真实余额、供应商价格或生产配置。

## 需求与工作流

产品方向优先从“产品方向：”“我想做的方向是：【…】”“Product direction:”或“Starting direction:”提取。Skill 名称不作为产品方向，多个相互冲突的明确方向保留待确认。原始需求始终保留。没有明确站点时仍应询问，不能因调用预算而默认美国站。

五个 Skill 顺序固定，第1阶段完成后等待选择细分市场，第5阶段完成后等待确认最终结论，两个决定均存在后才保存最终 HTML。不增加第3阶段业务确认。准备阶段无需创建任务、读取私人配置或请求市场数据。

单站点、最终研究一个细分市场、评论样本3–5个竞品时，host工作流规划为：

| 阶段 | 付费市场调用规划 | 依据 |
| --- | --- | --- |
| 1 细分筛选 | 8–10次 | 挖词、需求验证和3–5个候选方向 |
| 2 市场深研 | 6–10次 | 一个选定市场及头部竞品 |
| 3 差评分析 | 4–8次 | 3–5个竞品，必要时补页 |
| 4 关税到岸成本 | 通常0次 | 复用市场数据，税率证据和报价另行核实 |
| 5 评分决策 | 0–2次 | 复用已有证据，缺项再补 |
| 合计 | 约18–30次 | 研究计划估算，非供应商报价、观测值或硬上限 |

真实工具可用性仍由认证后的注册目录决定；预测不证明相关工具已经接入。积分价格未知不妨碍展示规划调用范围，不得自创15次等额度。

## 新任务默认不限次数

- MCP `research_start` 的 `maxMarketCalls` 可省略。省略创建 `budgetMode=uncapped`；填写正整数创建 `reviewed`，取消30次的固定最大值。网页相同，留空表示不限额。
- 显式 `reviewed` 必须提供次数；`uncapped` 不可同时提供次数，防止含糊覆盖。
- 首个付费请求之前仍展示站点、任务对象、五阶段只读动作、规划范围、未知价格及授权模式，取得该具体任务授权。后续同范围查询沿用该授权，不重复审批。
- 授权快照保存 `budgetMode`。没有此字段的旧任务授权按有限额度处理；旧任务不被迁移成不限额。旧的有限额度standing consent也不能静默升级为不限额授权，新任务须单独批准一次。
- 不限额只取消本研究任务的来源/工具调用次数天花板，不改变已有 `MarketCallAccount` 余额，不给账号充值，不绕过组织/工作区/owner、RBAC、设备授权、工具schema检查或只读边界。
- 原有调用账户继续按一次市场请求预扣一次；这是历史调用额度，不是新的货币研究积分。二者分别呈现，不将历史10000次额度解释为¥100。
- 明显偏离规划时自动保存暂停：阶段付费请求达到规划上界的两倍（最低2次）后，下一次请求前暂停。人工审阅后通过现有resume恢复，恢复本身不请求市场数据；再次超出一个阶段规划范围后可再次暂停。不是硬额度，不新建任务、不自动扩额。
- 重复请求、未知请求结果及中断仍走原有保护；成功请求价格未知时保持待核实，不重复索要逐笔许可。用户批准的任务包含价格未知项时才可执行，不能把未知写成免费。

## 研究积分规则 v1

1研究积分 = 人民币0.01元。供应商积分和货币费用经可追溯转换后都归为研究积分：

`研究积分 = 原始数量 × 每原始单位人民币 × 100`

每笔保留三位小数（四舍五入到0.001积分），汇总使用整数毫积分。原始单位支持CNY、USD及供应商积分；CNY兑换率固定1，其他单位必须填写并核实兑换率、日期和来源。不同供应商的原始积分不可直接相加，不默认一次请求等于一研究积分。

每笔字段：原始数量、原始单位、每原始单位人民币、兑换日期、来源、凭据、estimated/confirmed性质。已确认、估算和待核实分别展示；有任何未知或仅估算记录时，总实耗返回null，同时仍展示已确认部分。零费用只有明确0的凭据才能登记。汇率、供应商积分单价未取得时不预填、不自动生成。换算函数拒绝负数、溢出、非法日期、缺失凭据和CNY非1兑换率。

网页“登记研究费用与积分凭据”支持登记、估算和纠正；MCP新增 `research_record_charge`，需要该工具授权及实时 `agents:approve` 权限，引用用户明确确认并提交当前revision。该工具既不执行请求，也不清除BILLING节点、不充值、不扣现有账户余额。费用纠正追加 `creditAdjustments`，保留旧凭据，只汇总最新值。COMPLETED/CANCELLED或已保存报告的任务不接受费用变更，避免改写定稿快照。

记录存在既有PostgreSQL `AgentExecution.output` 研究快照内，由原有scope校验、租约/CAS持久化；没有新增Prisma模型或数据库迁移。模拟测试使用临时文件repository；测试文件不是生产事实源。

MCP read/start/step返回 `credits`；网页审计区、阶段报告和最终HTML展示相同换算口径及凭据。旧的provider usage字段保留原单位用于兼容审计，不作为统一研究积分。AI模型费用未取得凭据时继续列为未知，不虚构已包含模型费用的完整总成本。商品采购、关税及物流属于商品利润测算，和研究服务积分分开。

本次只修改源码、mock测试和文档，不运行市场查询、真实扣费、充值、配置更新、数据库迁移或部署；不重启本地/生产服务。当前MCP连接的已加载schema不会因本地编辑而自动更新，必须在用户明确要求更新目标环境后发布并重新获取目录。
