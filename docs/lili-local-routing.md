# 本地 Lili 路由

## 当前实现（2026-11-06）

Lili 已作为本仓库原生模块提供 `/lili` 和 `/lili/v2/*`。使用主系统登录和权限；不再需要启动 43123 或独立 Lili 数据库。主系统当前本机地址为 `http://localhost:3017/lili`，端口仍由主系统启动参数决定。

技能、工具定义和工作流来自受版本控制的目录；`/lili/v2/tool-config` 提供卖家精灵和西柚配置，卖家精灵共用主系统设置接口，西柚按组织／工作区／用户加密保存。团队旧地址进入账号管理。未映射的业务执行器、充值和旧独立库记录不会自动启用或迁移。完整迁移去向见 `docs/lili-integration-delivery-2026-11-06.md`；逐页缺口与本次恢复边界见 `docs/lili-page-audit-2026-11-06.md`。
