# Round H2：赛狐真机只读排布（2026-10-25）

以用户真机截图与确认事实为准：销量统计默认宽表，不默认日期矩阵；销售利润无日期矩阵；在线商品显示 7/14/30 天列；广告产品保留分析与禁用归档；FBA 与 AWD 区分。

- `/sellfox?domain=sales` 默认宽表；`salesView=matrix` 为高级日矩阵，可前进/后退恢复。日期窗口和聚合仍复用现有本地读取，最多 90 天，不扩大同步范围。
- 图片/ASIN/店铺站点为左侧固定列；分析图标打开已有本地详情，销量和利润无右侧操作列。运营与销量洞察无本地来源，保持灰色占位。
- 店铺筛选使用搜索、checkbox、全选搜索结果、清空；未选仍表示全部店铺。筛选顺序为站点、店铺、业务筛选、日期、币种/粒度、搜索、重置。
- 默认每页 20，保留原分页选项。表内汇总及底栏汇总可见，库存只对本页已知值求和并注明最新快照；缺失不补零，金额按币种拆分。
- 销售利润优先展示毛利润、毛利率、销售额、订单量、FBA可售、销量、折扣/包装费灰列、广告花费。自定义列按商品信息、指标、赛狐待接分组。
- 在线商品使用“详情”，突出 7/14/30 天销量；广告左轨为广告组合空态待接，不生成虚构组合。FBA 页保留现有库存列，库龄无来源不展示，AWD Tab 禁用待接。
- 补货页保持列表；经营中台标注 Amazon 库存快照，赛狐 FBA 库存通过只读深链进入。不调整 API、权限、同步、Ads apply 或写回。
- 销量 CSV 通过现有显式列参数跟随当前宽表/日矩阵；分析入口导出空白，不伪造业务字段。Agent 窄表导出不变。

验证：真实 Tailwind 的隔离 Playwright 浏览器回归覆盖默认宽表、视图切换、checkbox 店铺、列选择、汇总、720/1440（另含360）布局、详情和只读请求；TypeScript、相关 ESLint 及核心读取测试（经用户授权同步两处旧默认矩阵/列序断言）。不需数据库、账号、生产服务或同步。
