## 行为

- ResearchEngine 默认不生成首次付费 MCP_CALL、不因未知扣费生成 BILLING、不因纯规划偏差新增费用暂停；用户明确设置的调用上限、账户计量、身份权限和 Schema 校验保留。
- 费用要求由研究原始要求与当前阶段 Skill 原文识别（中英文明确要求语句，排除否定语句），不是由供应商响应或模型输出授予。其他阶段 Skill 的要求不提前触发当前阶段费用审批。不修改供应商 Skill 原文/哈希。
- 未知结果作为失败请求保留，billing 仍 UNKNOWN、金额不补 0、原始敏感响应不保存；不同请求可以继续。相同工具及参数的重复调用仍拦截；此改动不发起自动重试。
- 历史 MCP_CALL/BILLING 默认门槛可在 step/resume 时解除，不制造人工决定或账单回执；resume 本身不调用外部工具。当前用户/Skill 明确要求的费用门槛继续保留。历史任务只在下一次合法恢复/推进时应用，不批量修改数据库。
- NICHE/FINAL 业务选择、凭证、权限、真实账单记账校验保留。删除费用批准不代表费用为零，不删除费用审计记录，不自动改供应商收费。
- MCP initialize instructions、manifest、市场访问 metadata、研究工具说明和 nextAction 同步：不得因系统默认付费要求再索要批准。服务端 metadata 表示默认策略，具体任务仍返回 feeApprovalRequired。
