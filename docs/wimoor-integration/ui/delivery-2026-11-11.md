# Wimoor 内容移植交付记录

日期：2026-11-11。范围：本地开发与隔离浏览器验证。导航布局保持当前样式；本轮只统一重复目标、升级页面内容。22 项检查范围不代表已完成所有 Wimoor 功能。

## 已实现的内容

1. **仓库入口收敛**：侧栏、经营中台与旧 URL 全部指向现有 `/logistics/warehouse?tab=...`，复用 WMS 页面、权限和服务；旧仓库说明路由转向真实业务页。WMS Tab 切换、刷新、后退保留当前子页。
2. **采购列表升级**：参考 Wimoor 状态 Tab→筛选→工具栏→列表→详情/操作的顺序；新增单据弹窗、详情抽屉、有限集分页，保留原有下单和关联 WMS 收货流程。订单单价保持字符串精度，未将财务数值转为浮点显示。
3. **供应商页面升级**：共用采购工作台，列表优先；搜索名称/联系人/电话/邮箱，添加/编辑使用原 API 与弹窗，窄屏可操作。没有第二套供应商主档。
4. **订单详情链路**：列表订单号可打开抽屉，保留未知状态/缺失字段语义，链接同订单的现有商品明细页；没有另加包含个人信息的详情请求。财务仅调整筛选/表头呈现。
5. **未接入布局**：头程物流、FBA 装箱、ERP 费用各有真实源码参考的 Tab/表头与接入状态；可查看 API/Service/模型缺口和现有相关入口，无假业务行及伪执行按钮。
6. **共用组件**：WorkbenchDialog 提供原生 modal/抽屉、Escape 与焦点约束；WorkbenchPagination 提供有限集分页和范围说明。切换工作区/加载失败清除旧采购行和详情；客户端写按钮按现有权限禁用，服务端权限仍由原 API 执行。

## 后端缺口与剩余工作

- 采购 API 当前最近 100 单、供应商最多 200、商品最多 500；本轮分页/搜索仅作用于已加载集。全量搜索/游标和一致的服务端查询层仍待补齐，未新建平行业务服务。
- 供应商/采购现有 mutation 事务、WMS 关联和状态转换沿用；本轮未验证真实落库、并发、审批与长流程补偿。
- 头程承运商/报价/订舱/轨迹与费用关联缺 API、Service、模型。
- FBA 装箱方案/分组/提交/标签、创建入库计划/确认货件/购运等真实写入未接；Logistics 仍只负责文件准备。
- ERP 费用、报销审批、付款/核销/总账凭证未接；Amazon 财务/结算不是这些能力的替代品。
- 第三方/海外仓复杂模型、完整跨仓在途单据未按 Wimoor 功能对等验证。广告演示和真实视图需按各数据提供者单独验收。
- 商品/账号/库存/报表/广告/系统其余 Wimoor 页面仍是映射与现有页面沿用，不能称为已逐页移植；完整菜单业务流程需持续人工核对。
