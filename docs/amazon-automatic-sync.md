# 美国／加拿大自动同步（2026-11-06）

用户已批准：有效 SP-API 授权和美国／加拿大数据源就绪后自动开始最多 730 天历史回溯，完成后每日增量；不需要人工另建计划或逐窗口批准。此文记录本次本地源码变更，不代表已经部署或开始真实同步。

## 执行条件与范围

- 沿用 `AMAZON_SYNC_CENTER_SCOPES` 精确组织／工作区开关、Redis worker 和现有 30 秒调度 tick。服务器未部署此版本、未应用迁移、未运行标准 worker 或范围开关未启用时，不会自动运行。
- 已验证 `CONFIGURED` 授权必须有真实 Seller ID，来源已绑定 ERP 店铺记录，Marketplace 为美国 `ATVPDKIKX0DER` 或加拿大 `A2EUQ1WTGCTBG2`。自动计划不再要求来源 `enabled=true` 或 ERP 店铺 `status=active`；绑定关系本身触发计划发现。手动任务仍保留原启用及店铺状态校验，自动计划可通过暂停操作停止未来任务。
- 订单及财务使用已有来源策略中的应用标识、管理员角色声明、预算和时区；缺策略不能执行。参与站点查询不证明业务角色。财务仍是卖家级单源，必须满足已有所有参与站点及同一 ERP 店铺绑定校验；含额外站点时不会缩减或伪造授权范围。
- 自动计划还覆盖退货、结算发现、赔偿与库龄当前快照、FBA 库存事件，以及来源策略明确列出的在途计划、Listing SKU、Catalog ASIN 和价格 ASIN。需要完整报告周期推进的 Brand Analytics/Buy Box 与隔离中的 Amazon Ads 报表采集不自动启动。

## 窗口、持久化与恢复

调度器为每来源创建唯一 `auto-v1:<sourceId>` 计划，幂等 ID 和目标关系在同一作用域锁事务中提交。管理员必须仍为组织 owner/database_admin 并具备 create/approve 权限；计划创建有审计。停用的已有自动计划不会被扫描重新启用。

首次自动计划将订单／财务／退货策略起点固定为计划创建时刻前 730 天，并递增数据源 revision；订单每个任务最多 1 天，财务与退货最多 30 天。订单详情沿用来源策略中的详情选项与独立预算。退货报告表示 FBA 仓库已接收退货，不代表所有退货渠道或完整退货全集。新域通过已生成自动计划启停；不允许创建额外自定义计划，计划范围和频率不可改。来源绑定所需的对象清单由既有审批策略提供，不自动发现店铺商品全集。

FBA 库存事件最多回看 540 天，每个报告最多 31 个闭合日期；失败重试原窗口，成功后推进下一段。结算报告 `getReports` 的创建时间过滤最多 90 天，计划只做最近 90 天滚动发现，不声称结算行具有 730 天覆盖。日报按已成功完整报告的日期覆盖计算下一缺口，每次最多 31 个已闭合业务日，目标为最多 730 天；Amazon 实际保留和资格限制可能缩短覆盖。

在线商品、FBA 库存、赔偿、库龄和来源策略中明确列出的在途计划、Listing SKU、Catalog ASIN、价格 ASIN 只刷新当前策略对象/当前快照；不会重建 730 天快照历史，也不会自行发现全部货件、SKU 或 ASIN。已有活动任务／未完成游标时等待处理，不清空密文游标；已有成功游标不被计划发现过程修改。

日报按已成功完整报告的日期覆盖计算下一缺口，每次最多 31 个已闭合业务日，从当日业务日期前 730 天到昨天；仅成功完整报告推进覆盖，失败或部分成功不会冒充完成。API 历史保留和资格限制仍可能导致不足 730 天，不能承诺 Amazon 一定返回全部历史。当前快照仅有在线商品和库存现状，没有历史快照重建。

每个来源同时最多一个活动任务，重复 tick 不重复任务。Redis intent 恢复、租约、fence、密文分页、已提交页幂等、429/5xx 有限重试继续复用现有实现。失败重试耗尽、API 拒绝、报告创建结果不确定等停止推进，不无限新建任务或重复申请远端报告。任务有界；原始报文和 PII 不向普通 API/UI 暴露。

自动任务以启用的计划、目标、版本和实时管理员权限作为持续执行依据；手动任务保留独立执行审批和 24 小时截止。自动任务每次请求及提交前仍核对来源、授权 revision、角色与范围。计划暂停、版本变化或来源停用会阻止旧任务继续请求；管理员可通过同步中心的计划管理操作暂停／恢复已生成计划。暂停只阻止未来任务，并使在途任务在下一次检查时停止；API 凭证不会写入仓库。
