# Sellfox 店铺名称点击导致标签页崩溃

2026-10-26，用户报告在 aecob `/sellfox` 店铺多选框点击其他店铺名称时，
Chrome 显示“错误代码：5”，内置浏览器也显示页面崩溃。刷新可恢复，但不构成修复。

现场操作确认：直接点击复选框可以更新店铺筛选；点击名称时，原生 `details`
的 `onBlur` 会在 `relatedTarget` 为空时立即关闭面板，可能在 label 默认激活
关联 checkbox 前隐藏控件。现场还观察到点击落到下方表格，打开了记录详情。
未取得浏览器原生崩溃栈，不能将此竞态声明为错误代码 5 的唯一原因。

修复范围仅 `SellfoxShopFilter`：使用受控 button/div 弹层，保留名称关联复选框、
搜索、全选、清空和多选。点击内部名称不关闭；外部 pointerdown、外部 focusin
关闭；Escape 关闭并将焦点还给触发按钮。保留 URL 筛选和只读接口，不调用同步。
监听器仅展开时注册并在关闭或卸载时清理，不改变轮询和服务端查询。

定向回归增加无目标失焦后点击名称、反复选择两个店铺/清空、筛选请求参数、
Escape 焦点恢复、点击外部关闭和无写请求断言。
运行 `npm run test:sellfox:browser`，发布通过既有 CI artifact 链路，
发布后须在实际浏览器按“展开→点击名称→再次切换”验收，不能只检查 HTTP 200。
