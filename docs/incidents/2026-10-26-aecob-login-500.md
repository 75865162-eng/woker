# aecob 登录页 500

2026-10-26（北京时间），aecob 当前发布 b711f26 的 `/login` 返回 500，
日志为 `Cannot read properties of undefined (reading 'kind')`，来自
Next.js `isRouteCacheOwner`。编译后的页面引用 `cacheOwner`，但服务器
Next.js 15.5.25 的 RouteModule 没有该字段。本地已安装 Next.js 15.5.28，
而提交的 lockfile 和服务器运行依赖均为 15.5.25；不能用本地构建替代 CI。

上一版 11f4f4d 在服务器内网临时端口验证 `/login` 返回 200，探测进程已停止。
用户选择保留当前功能，以本地提交为准经 GitHub Actions `npm ci` 重新构建，
发布目标为旧服务器 159.75.203.221。数据库、环境变量及文件不做恢复或覆盖。

原健康检查只访问 `/`，登录重定向 307 会被 curl 视为成功，即使登录页 500。
默认探测改为 `/login`，保留 `HEALTH_URL` 覆盖能力，失败沿既有应用回滚流程处理。
发布后须读取 RELEASE-RESULT.json，并验证公网登录页返回 200、静态资源可访问。
