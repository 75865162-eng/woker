## 权限行为

移除订单、财务、退货、结算/赔偿/库存报表、履约/定价/商品详情/品牌等域的 `approvedRoles` / `rolesAttestedAt` 手工登记执行门槛。保留旧函数签名及旧数据兼容，字段仅作历史元数据；不新写角色、不重加密凭据、不重置授权身份。operations 授权表单不再提交/显示角色输入，品牌采集不再要求每次勾选资格。旧 brandEligibilityAttested 字段为策略兼容保留，不代表新产生的人工证明。

账号设置中的成员 RBAC、组织/工作区/Seller/Marketplace 数据授权仍由服务端实时校验，原有 create/edit/approve/export 边界不变。已提供的 API 访问证据仍验证其身份/版本/站点绑定；真实 API 资格与能力由 Amazon 响应决定。403、无资格、取消、超限不得伪造成功或反复创建。撤销账号权限仍应阻断恢复任务，测试改用账号权限撤销验证，不能继续将清空旧 API 角色列表当作账号撤权。
