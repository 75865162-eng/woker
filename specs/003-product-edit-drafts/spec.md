# 商品编辑草稿与并发保护

日期：2026-10-20。性质：数据保护缺陷修复（P0）及编辑体验升级。

## 目标与范围

编辑自动暂存、刷新可恢复、明确取消/关闭确认后放弃、点击保存才正式提交。复用 ProductRecord、PostgreSQL revision CAS、聚合事务、审计版本和 Outbox，不新增数据库草稿表或第二事实源，不改列表查询架构。

## 用户故事与验收

1. 基本资料、工作簿、图片引用、结论 Excel、视频策划修改后，防抖写入 IndexedDB。显示正在暂存/已暂存/失败；不调用正式保存 API。
2. 刷新、意外退出或暂时离开保留草稿；同账号同工作区同商品重开提示恢复/放弃。恢复保留原 baseRevision，旧草稿不得冒充最新数据。
3. 取消或关闭：无修改直接退出；有修改应用内确认，继续编辑保留，确认放弃清理草稿，正式数据不变。
4. 保存提交完整表单和预期 revision；数据库更新条件包含 revision；事务成功后清草稿并刷新列表/详情。失败保留表单，提交中禁止重复保存。
5. 409 使用应用内 Dialog，提供加载最新、恢复我的修改、暂不处理、放弃草稿。先读权威详情，再允许恢复修改到最新基线，人工检查后保存；不自动提交，再次冲突重复处理。
6. 草稿按 organizationId/workspaceId/userId/entity/editorType 隔离；包含 schemaVersion、baseRevision、原始快照、表单、updatedAt。不存凭据或附件二进制。存储失败不得阻断正常编辑。
7. 附件上传不等于正式绑定；恢复复用文件引用，不重新上传；放弃不删除共享文件，复用临时/orphan 机制。不能确认安全的对象删除不得执行。
8. 视频接口和历史恢复使用客户端观察到的 revision；事实源维护脚本走聚合事务，纯派生 SQL 不覆盖 payload/revision。

## 浏览器兼容性

兼容性补充（2026-10-21）：HTTP IP 或旧浏览器缺少 crypto.randomUUID 时，草稿初始化不得导致页面崩溃；草稿存储仍按原身份和 revision 隔离。HTTP IP 与 HTTPS 域名属于不同 origin，不跨 origin 搬迁本地草稿。

## 非目标

字段级三方自动合并、批量任务系统、Redis/新队列/微服务、附件系统重构、服务器发布。

## 风险与上线准入

浏览器强杀前最后一次异步 IndexedDB 写入无法绝对保证；页面隐藏/离开时尽力 flush，不在生命周期删除草稿。草稿存于设备，清理浏览器数据后不可恢复。附件 orphan 标记尚不等于对象存储物理删除，不新增危险 GC。验证纯函数、存储故障、CAS、类型、lint、构建，并记录真实浏览器与双用户数据库验证缺口。回滚仅回滚代码，无数据库迁移；保留本地草稿库。
