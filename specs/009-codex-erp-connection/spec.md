# Codex ERP 连接

日期：2026-11-07。性质：认证入口缺陷及客户端连接阻断。

## 用户场景

用户在 Codex 对话直接查询一个明确店铺和站点的库存，获得数据库中已同步的真实记录，并理解来源、时间和范围。网页可见、工具目录可见或隔离 fixture 查询成功均不能代替真实验收。

## 要求

- 外部客户端无需浏览器登录 Cookie，但每次调用必须通过个人 Bearer 认证。
- 仅业务 MCP 精确入口采用该方式；相邻路径与凭证管理入口保留原认证。
- 工具及行数据受当前用户权限、显式 MCP 授权、凭证工具/范围和有效数据源共同限制。
- 跨组织、工作区、店铺、站点与 Ads Profile 不泄漏；撤权、停用或断连后不能继续查询。
- Skill 指导范围发现、字段与粒度核对、失败处理和带来源回答。
- 凭证、真实授权和客户端配置须按仓库规则独立批准；无工具时如实报告连接未完成。

## 成功标准

隔离正反向用例通过；至少一次对话中的真实 MCP 工具调用返回指定店铺非空记录，包含来源和时间信息，并可在 ERP 调用记录核对。当前后者待完成。

## 范围假设

本次修复仅本地，不部署；首个真实验收限库存，不申请 Ads、同步、导出或修改权限。卖家精灵、西柚与建议写回另行验收。
